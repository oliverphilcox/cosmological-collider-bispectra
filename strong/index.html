$$\frac{\mathcal{L}}{a^3} = \tfrac{1}{2}\!\left[\dot{\pi}_c^2 - c_{\rm rel}^2\tfrac{(\partial_i\pi_c)^2}{a^2}\right] + \tfrac{1}{2}\!\left[\dot{\sigma}_c^2 - \tfrac{(\partial_i\sigma_c)^2}{a^2} - m^2\sigma_c^2\right] + \color{#ff7f0e}{\rho\,\dot{\pi}_c\,\sigma_c}$$

$$\color{#1f77b4}{-\,\lambda(\partial_\mu\pi_c)^2\dot{\pi}_c - \Delta\lambda\,\dot{\pi}_c^3}\;\;\color{#ff7f0e}{-\,\tfrac{\kappa}{2}(\partial_\mu\pi_c)^2\sigma_c - \tfrac{\Delta\kappa}{2}\dot{\pi}_c^2\sigma_c - \tfrac{\alpha}{2}\dot{\pi}_c\sigma_c^2 - \mu\,\sigma_c^3 - \beta\tfrac{\partial_i\pi_c\partial_i\sigma_c}{a^2}\dot{\sigma}_c}$$

with $c_{\rm rel}=c_\pi/c_\sigma$, scalar mass $m$ (in units of $H$), and mixing strength $\rho$ (non-perturbative). The cubic couplings $\Delta\rho,\,\tilde{c}_3,\,\alpha,\,\mu$ are set directly by the sliders.

Each $\sigma$ leg requires one $\rho$-insertion, so vertices with 1, 2, 3 $\sigma$ fields give single, double, triple exchange (plotted separately). Shapes are interpolated from a finite grid and carry some residual numerical noise.
